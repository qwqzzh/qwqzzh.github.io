PART 1

Problem setup · from a glass plate to RGB

One plate.
Three exposures.
One color image.

Prokudin-Gorskii recorded the same scene three times through blue, green, and red filters. The digitized plate stores those grayscale exposures vertically in B–G–R order. Because the plate or camera moved slightly between exposures, directly stacking the three arrays produces colored ghosts. The task is to estimate one 2D translation for green and one for red, both relative to blue, then form an RGB image.

The reported displacement is (dy, dx): positive dy moves a channel downward and positive dx moves it to the right. Once the two translations are estimated, only the region supported by all three channels is retained.

KEY IMPLEMENTATION

Split without losing plate data

The height of one exposure is ⌊H/3⌋. Any extra scan rows below the third exposure are ignored, and pixel values are converted to floating point before similarity scoring.

# pseudocode
h = floor(total_height / 3)
B = plate[0:h]
G = plate[h:2h]
R = plate[2h:3h]
PART 2

Single-scale exhaustive alignment

Start small,
search everything.

For each moving channel M and fixed blue reference B, I enumerate every integer translation d = (dy, dx) in [−15, 15]². The best displacement maximizes a similarity score S on the interior image content:

d* = arg maxd∈[−15,15]² S(B, shift(M,d))

A crucial detail is the scoring window. I intersect the pixels that remain valid for every candidate shift, then remove another 10% interior margin. Every candidate is therefore measured on the same number of pixels. The final translation function writes uncovered pixels as black rather than using wraparound.

SEARCH LOGIC

961 candidate translations per channel

The low-resolution method is intentionally direct: two channels × 31 × 31 scores. This makes the result easy to reason about and satisfies the single-scale requirement.

# pseudocode
for dy in -15 … 15:
  for dx in -15 … 15:
    score = similarity(B_window, shifted_M_window)
    keep the displacement with the largest score
PART 3

Coarse-to-fine image pyramid

×2 · REFINE ±2

FULL RESOLUTION

Large motion,
without a large search.

A 31×31 search at full TIFF resolution repeatedly scores millions of pixels. Instead, I build a pyramid by averaging each 2×2 block before decimating by two. Filtering before downsampling reduces aliasing. Pyramid construction stops when the longest side is at most 400 pixels.

The coarsest image uses the full ±15 search. Moving one level finer doubles the displacement estimate because a coarse pixel covers two fine pixels; only a ±2 residual correction is then searched. If dℓ+1 is the coarser estimate, the next estimate is:

dℓ = 2dℓ+1 + arg maxδ∈[−2,2]² S(Bℓ, shift(Mℓ, 2dℓ+1+δ))

  • Coarsest search±15 pixels
  • Refinement±2 pixels per level
  • Scoring areafixed valid overlap, inner 80%
  • Runtimeall final images under 25 seconds
PYRAMID LOGIC

Large motion becomes a small correction

The same exhaustive aligner is reused at every scale. Only its search center and radius change, which keeps the implementation compact and testable.

# pseudocode
offset = search(coarsest, center=(0,0), radius=15)
for each finer level:
  offset = 2 × offset
  offset = search(level, center=offset, radius=2)
PART 4

Similarity metrics · NCC and Euclidean L2

NCC and true
Euclidean L2.

Euclidean L2 directly measures pixel disagreement. It is sensitive to brightness and contrast differences across filter channels, but is simple and effective when their intensities are comparable. The implementation evaluates the exact norm—not mean squared error—and negates it because the search routine maximizes scores.

L2 score(A,B) = −√Σᵢ(Aᵢ−Bᵢ)²

Zero-mean normalized cross-correlation first subtracts each window’s mean and divides by its energy. It compares pattern shape instead of absolute intensity and is therefore more tolerant of global brightness and contrast changes.

NCC(A,B) = ((A−μA) · (B−μB)) / (‖A−μA‖₂ ‖B−μB‖₂)

METRIC LOGIC

One maximization interface

Both metrics return a score to maximize. Keeping a shared interface lets the same exhaustive search and pyramid code switch metrics without changing alignment logic.

# pseudocode
if metric == "ncc":
  return dot(center(A), center(B)) / energies
if metric == "l2":
  return -euclidean_norm(A - B)

PART 5

Failure analysis · Emir

Why raw pixels
fail on Emir.

The Emir’s blue robe is bright in one filtered exposure and dark in another. Corresponding pixels therefore do not have corresponding intensities, violating the assumption behind raw-pixel comparison. The problem is especially severe for the red channel: raw NCC settles on R (141, −205), while L2 gives R (103, 57), and neither is visually correct.

The large disagreement between two otherwise reasonable metrics is useful evidence. Rather than treating one metric as universally correct, I use their disagreement as a confidence signal that raw intensity is unreliable for this channel.

PART 6

Improvement · more advanced is not always better

Use edges
only when needed.

Gradient magnitude emphasizes structural boundaries that remain stable even when colors change. For each channel image I compute horizontal and vertical finite differences and combine them as E = √(Gx² + Gy²). Edge NCC correctly aligns Emir at G (49, 24), R (107, 40).

My first attempt forced edge matching on every plate. That solved Emir, but shifted Three Generations from the better raw result G (53, 14), R (112, 11) to G (54, 12), R (111, 9), making color outlines around the people more visible. A sophisticated feature is not automatically the best feature for every image.

The final method selects features independently for green and red. It first computes raw NCC and raw L2. If both coordinate estimates agree within two pixels, the raw result is trusted. If they disagree, that channel alone is recomputed with edge NCC. This fixed rule triggers for the red channels of Church and Emir; every other channel retains raw pixels.

ADAPTIVE RULE

Agreement acts as confidence

The threshold is fixed and applied to each channel independently. No filename checks or hand-tuned offsets are used.

# pseudocode
d_ncc = pyramid_align(raw, metric=NCC)
d_l2  = pyramid_align(raw, metric=L2)
if max_coordinate_difference(d_ncc, d_l2) ≤ 2:
  use the requested raw metric
else:
  use pyramid_align(gradient_magnitude, metric=NCC)

PART 7

Improvement · automatic border removal

Detect the frame,
don’t guess a margin.

The initial version removed only invalid shift overlap, so black, white, and colored plate borders remained. A fixed percentage crop would hide them, but it would discard different amounts of real content from different scans.

The automatic detector forms three one-dimensional profiles along every edge: median luminance, median channel disagreement max(R,G,B)−min(R,G,B), and the fraction of nearly black or white pixels. After smoothing, it estimates normal transition noise from the central 50% of the photograph and selects the last statistically unusual transition in the outer 10%. Selecting the last transition is important because many plates contain nested white and dark bands.

A small guard band removes antialiased fringes. A second conservative corner test detects a dense clipped high-chroma block touching two adjacent edges—the case that caused the green square on Self Portrait—then removes only the shallower affected strip. All thresholds and proportions are fixed for the complete dataset.

BORDER SIGNALS

From 2D frame to four 1D decisions

Full edge lines handle ordinary and nested borders; the corner test handles localized saturated blocks that line medians intentionally ignore.

# pseudocode
profile = luminance_change
        + 0.75 × chroma_change
        + 0.50 × clipped_fraction_change
threshold = max(0.008, 2 × central_noise_98th_percentile)
crop after the last outer transition above threshold

PART 10

Limitations · what translation cannot fix

A sharp scene can still contain color ghosts.

In Three Generations and Harvesters, buildings, rails, and ground align sharply while small colored fringes remain around people. The exposures were captured sequentially, so a moving subject does not occupy the same position in every channel. One global integer translation cannot correct this local motion without damaging the static background.

LIMITATION

Global translation models camera or plate shift—not independent object motion.
